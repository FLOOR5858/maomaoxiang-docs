# 售后与支持

> 这是模板，条款需要你根据实际经营方式确认后发布。结构参考了成熟硬件厂商的做法：支持渠道 → 保修范围 → 返修流程 → 运费规则。

## 技术支持渠道

| 渠道 | 用途 | 状态 |
|---|---|---|
| 文档与 FAQ | 首选，覆盖烧录、接线、SDK 常见问题 | 已上线 |
| 邮箱 | 订单相关与具体问题 | 待补充邮箱地址 |
| GitHub Issues | SDK / 文档问题 | 仓库公开后可启用 |
| 微信群 / 论坛 | 开发者交流 | 待确认 |

## 保修范围

- 待确认：保修期限（建议 12 个月）
- 待确认：覆盖哪些故障（元器件失效、焊接问题等）
- 待确认：不覆盖哪些情况（供电错误、自行改装、静电击穿等）

## 返修流程

1. 通过邮箱提交订单号、故障现象、照片/视频
2. 确认后寄回，随货附订单号与联系方式
3. 收到后检测并反馈
4. 待确认：检测周期、维修或更换规则

## 运费

待确认：7 天内质量问题谁承担运费、Other 情况规则。
