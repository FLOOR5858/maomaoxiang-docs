# 常见问题

以下问题模板基于 RV1106 平台常见场景整理，带 `待确认` 的答案需要根据你的实际样机验证后填写。

## 烧录

**Q：如何进入下载模式？**
待确认：按住 BOOT 键上电 / 其他组合，以及成功进入的判定方式（USB VID:PID）。

**Q：烧录工具报 "Download error" 怎么办？**
待确认：常见原因与排查顺序（数据线、USB 口、供电、loader 版本、镜像与存储类型匹配）。

**Q：SPI NAND 与 eMMC 版本镜像可以混用吗？**
不可以。RV1106G2/G3 的存储介质不同，分区表和 loader 不同，必须选择对应版本。

## 硬件

**Q：SC233A 可以直接接到 RV1106G3 的 MIPI 口吗？**
电气上可行（10-bit RAW，1/2 lane），但需要设备树和驱动正确配置传感器型号、lane 数、时钟与 I2C 地址。待确认：你的 SDK 是否已包含 SC233A 驱动。

**Q：可以改用 DVP 摄像头吗？**
RV1106G3 支持 DVP（8/10/12/16-bit，最高 150 MHz），但本模组的 PCB 走线是否兼容待确认。

**Q：供电要求是什么？**
待确认：输入电压范围、各电源域电流、是否支持 PoE。

## 软件

**Q：NPU 算力 0.5 TOPS 还是 1 TOPS？**
以 Rockchip RV1106 Datasheet Rev2.2 为准：NPU 支持 INT4/INT8/INT16 混合，最高 1 TOPS。早期资料中的 0.5 TOPS 说法与该版本手册不一致。

**Q：RV1106G3 的片内内存多大？**
官方手册 §1.2.2 写明 RV1106G3 为 SIP 2 Gb DDR3L，按 16-bit 折算即 256 MB。网上流传的 512 MB 说法没有在官方手册中找到依据。

**Q：支持哪些系统？**
待确认：Buildroot / Ubuntu / Debian 的实际支持情况与镜像下载地址。
