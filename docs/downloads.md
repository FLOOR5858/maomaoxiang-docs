## 建议的托管方式

参考幸狐的做法：**PDF 直接放 Git 仓库，用 raw 链接直链；大体积镜像放网盘**。

- GitHub 仓库：面向海外用户，作为权威源
- Gitee 仓库：国内用户下载更快
- 百度网盘 / Google Drive：系统镜像等大文件

每条下载链接都写进这个表格，用户不需要跳转多个页面。
